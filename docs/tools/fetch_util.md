# fetch_util.py 说明

## 用途
为仓库维护脚本提供统一安全 HTTP GET 能力。

## 安全约束
- 只允许 HTTP(S) 公网地址，校验 DNS 解析结果。
- 重定向逐跳重新校验，限制重定向次数。
- 限制连接/读取超时、重试次数和响应体大小。
- 拒绝 localhost、局域网和非公网 IP。

## 使用
由 API、直播和在线包工具调用；不负责解析 TVBox 配置内容。

## 主机熔断与请求预算

- 所有 SafeFetcher 实例共享线程安全的主机级熔断状态。
- 同一主机连续 4 次网络失败、HTTP 408/429 或 5xx 后打开熔断，默认冷却 60 秒。
- 冷却结束后只允许一个半开探测；成功响应恢复主机，失败则重新进入冷却。
- HTTP 404 等普通 4xx 表示主机可达，不累计熔断失败。
- 每个 URL 默认总请求预算 30 秒，覆盖重试、重定向和响应体读取；可通过 fetch_bytes(total_timeout=...) 调整，传 None 可关闭总预算。
- 熔断只影响请求调度，不删除缓存；调用方仍按各自规则保留旧文件。
