# TVBox-Config

TVBox 点播配置、直播源及检测工具的整理仓库。

- [仓库目录与检测标准](docs/REPOSITORY_STRUCTURE.md)
- 点播源：`sources/vod/`
- 直播源：`sources/live/`
- JS/JAR/待检查源：`sources/js/`、`sources/jar/`、`sources/pending/`
- 检测工具：`tools/`
- 检测输出与报告：`output/`

注意：文件已收录不等于源可用；HTTP 成功、返回有效影视数据、实际播放成功是不同的验证等级。请以 `output/reports/` 中的检测记录为准。
